# Sound-Konzept: Folge 1 – Das Flüstern des Goldes

Dieses Dokument dient als akustische Regieanweisung für die Produktion der ersten Hörbuch-Folge. Es definiert die Soundeffekte (SFX), die musikalische Untermalung und die atmosphärischen Layer.

---

## 1. Atmo-Layer (Grundstimmung)
Diese Sounds laufen dezent im Hintergrund der jeweiligen Akte:
- **Akt 1 (Heidi):** „Rich Lake“ – Sanftes, rhythmisches Plätschern von Wasser gegen einen Schiffsrumpf, entferntes Rufen von Möwen, das leise Summen einer Klimaanlage (High-End-Luxus).
- **Akt 2 (Helmut 1936):** „Industrial Grey“ – Ein tiefer, mechanischer Grundton, das ferne Dröhnen von Fabrikschornsteinen, der Hall eines großen, fast leeren Raumes.
- **Akt 3 (August W. 2026):** „Fluorescent Stress“ – Das nervöse Summen von Neonröhren, das ferne Gemurmel in einem Gerichtsflur, das Reiben von Stoff auf Leder (Unruhe auf der Anklagebank).

---

## 2. Spezifische SFX-Cues (Zeitstempel-basiert)

| Segment | Aktion / Dialogzeile | Sound-Effekt (SFX) |
| :--- | :--- | :--- |
| **Intro** | „Geld schläft nie...“ | **Ticken einer Patek Philippe**, das abrupt stoppt. Dann: **Schauer von Goldmünzen** auf Marmorboden. |
| **Akt 1** | „Geräusch einer Perlenkette...“ | **Klicken von Perle auf Perle** (extrem nahmikrofoniert), gefolgt vom **Rascheln schwerer Seide**. |
| **Akt 1** | „Rain of Gold“ (Grok) | **Synthetisches Donnerrollen**, das sich in das **Prasseln von Münzen** (wie Regen) verwandelt. |
| **Akt 2** | „Duisburg, 23. April 1936“ | **Hartes Klacken von Schreibmaschinentasten**, ein mechanischer **Wagenrücklauf**. |
| **Akt 2** | „Während die Tinte trocknet...“ | **Geräusch einer Feder auf Papier**, gefolgt vom **Zuschlagen eines schweren Tresors**. |
| **Akt 3** | „WhatsApp-Benachrichtigungstöne“ | **Serienweises Aufploppen** von iOS-Benachrichtigungen (überlappend, erzeugend ein Gefühl der Überforderung). |
| **Akt 3** | „Richtergabel-Schlag“ | Ein **dumpfer, hallender Schlag**, der digital verzerrt wird und in den Outro-Beat übergeht. |

---

## 3. Musikalische Leitfäden
- **Thema „Das Gold“:** Ein solitäres Cello, sehr tief gestimmt, spielt eine elegante, aber melancholische Melodie in Moll. Es symbolisiert die Last des Reichtums.
- **Thema „Die KI“:** Kurze, hochfrequente Glitch-Sounds und minimale Sinus-Töne, die den Übergang zwischen Grok und Gemini markieren.
- **Thema „Die Arisierung“:** Ein schleppender, fast militärischer Rhythmus, erzeugt durch das rhythmische Schließen von Archivschubladen.
