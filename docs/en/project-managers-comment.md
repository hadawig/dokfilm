# Project Manager's Comment: AI and I

I had the idea to "play" a bit with Gemini-CLI in the wake of the AI hype!
It started with a little preparation. Preparing the computer? That was very little work!

As a power Linux user for decades, a proud member of the Open Source community, and always running a perfectly functioning Tux machine (and if it’s not, I fix it with the highest priority), a few commands in the console were enough! 
Follow my lead:

```bash
sudo apt update
sudo apt upgrade
sudo apt autoremove
sudo reboot

sudo apt install npm
npm install -g @google/gemini-cli
mkdir gemini
cd gemini
gemini
```

Case closed! After the Gemini-CLI setup routine, I now have a usable and "virgin" AI system on my local machine.

To be honest, I didn't expect much. I know the common belief: for AI, you need a high-end Windows machine (yes, the one with the candy wrapper logo!) costing at least €10,000, with a €5,000 graphics card and half a terabyte of RAM (plus a 20A fuse and cheap electricity!). 
Not a chance here in Tyrol!

"Mine" has a TDP (Thermal Design Power of the CPU) of just 65W. No graphics card at all.
Nonetheless, I designed a system that turned out to be quite powerful.

Since I am interested in politics and forced to follow the ongoing corruption trials of the "Banana Republic of Austriastan," the idea was born to dedicate myself to an artistic and artificial (AI and I) reappraisal. 
What to do? I thought, if AI is as smart as everyone claims (I have a very different opinion, which I won't share here so as not to upset my "best employee"), I'll just ask my house-AI.

Now – 3 days later – there is a website online that was built and filled almost independently and flawlessly by Gemini-CLI under my guidance. In my opinion, it’s something to be proud of!
